# Keep Me in the Loop

- Apply the installed `keep-me-in-the-loop` skill before implementing changes.
- Read `KEEP_ME_IN_THE_LOOP.md` and classify intended work against its **Areas requiring a decision**.
- If work touches a listed area, inspect and write a concise proposal, then wait for explicit human acceptance before implementation.
- Routine work outside those areas may proceed normally.
- Keep proposal, human decision, implementation, and verification distinct.
- If the skill is unavailable, follow the same stop rule and tell the human.
